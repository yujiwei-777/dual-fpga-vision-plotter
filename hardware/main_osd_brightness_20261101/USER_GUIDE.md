# 主板紧凑中文 OSD

只读基线：`main_osd_large_font_20261030`，基线 bit SHA256：
`DF8495D9CCE502B1D24EC45605DC63EB1020B90777BBA417CDD416DED8A74164`。

本变体只调整 HDMI 两处信息面板及识别标签避让区域。摄像头、ISP、运动检测、普通 CNN、PCB 检测、文档复制、按键、HXA1、DDR、引脚和时钟约束沿用基线。副板继续使用原 bit。

## 字体与布局

- 中文采用原生 16×16 点阵，字身约15像素；英文和数字字身提高到约14像素，与中文保持接近的视觉高度和共同基线。全部固定在16×16字格，英文/数字保留半角笔形并居中，不再做纵向两倍放大。W/M等完整字形经过整数压宽，避免裁切。
- 右上面板从 336×208 缩为 336×128，位置保持 x=864、y=64，右边保留 80 像素安全距离。关闭运动检测后隐藏运动计数行，背景高度缩为 104 像素。
- PCB 面板从 320×136 缩为 288×96，位置为 x=24、y=584。检测固定框及检测范围完全沿用基线。PCB 模式只显示左下面板，保持基线的显示选择。
- 两处文字距离左边框8像素；右上最长20字格坐标行完整显示，并在右侧保留8像素留白。
- 帧号、X/Y、面积和运动计数显示十进制；延迟沿用一位小数毫秒。X/Y 使用完整接口位宽，不再丢弃 Y 高位。面积显示六位，超过显示范围时饱和至 999999。
- 固定标签和状态使用中文；保留 X/Y、KEY4、MS 等通用缩写。识别框旁的原类别标签及其他模式叠加保持基线行为。

## 颜色

| 信息 | 颜色 |
| --- | --- |
| 标签、按键提示 | 青色 |
| 帧号、坐标、面积、延迟、运动计数 | 黄色 |
| 模式值及 PCB 标题 | 紫色 |
| 有效目标、锁定、就绪、通过 | 绿色 |
| 等待、扫描、复核、无目标 | 黄色 |
| 失败、链路错误 | 红色 |
| 目标颜色名称 | 对应的红、绿、蓝色 |

两处面板继续使用深色底和细边框；修正基线中最后一级把动态文字颜色覆盖成白色的行为。

## 实现与验证范围

固定小字库以同步 BRAM ROM 存储，字模显式嵌入 RTL；运行时不需要电脑字体文件。地址寄存与字库读取总计两拍，保持原 HDMI 视频流水延迟。十进制转换在独立显示支路串行完成，不增加除法器或 DSP。

帧号与延迟来自同一组已提交元数据：在首行有效视频第4像素后启动96周期的十进制转换，避开垂直消隐期间延迟邮箱尚未提交的首帧旧值；转换在第64行OSD出现前完成。

源码隔离检查记录在 `reports/osd_source_scope.json`。仿真和物理构建结果以最终构建报告为准。诊断 bit 在实板显示确认前标为 `NOT_RUN`；离线预览不等于显示器实拍。
