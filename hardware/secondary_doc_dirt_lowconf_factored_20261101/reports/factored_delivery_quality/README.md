# 副板固定脏斑与等价低分输出验证

本目录仅汇总软件和 RTL 证据；不授权生成或交付 bit。完整物理门槛另行核验，实板状态为 `NOT_RUN`。

- 低分逻辑仅分离 hard reject 与 soft flag6；默认参数 0 保留旧行为，生产参数 1 保留真实低分。阈值 31/28/77、FC8、模型、PCB、稳定器及主板未改变。
- 精确源码局部对照通过：16,384 个布尔条件，RTL 2,097,160 次原始数值比较及 16,384 次保持周期；不宣称四态 X 或整板全域等价。
- 七套现工程回归、metric 边界、低分输出、6 个前端用例及附加生命周期/超时用例均通过。2 张实拍完整 RTL 链路复现：空白 2418 为 0 条路径；笔迹 2358 为 30 条路径、351 点、417 行 G-code。
- 51 帧软件对照是历史证据，不是 51 帧新 RTL 回放。5 张纸边/阴影空白图路径总数为 41 → 36 → 71，固定脏斑补偿不能当作通用背景去除。
- 缺少真实弱墨穿过脏斑的样本；合成 Y=96 漏 1/384、Y=104 漏 87/384 个目标点，浅墨仍可能丢失。机位、裁剪或读出方式改变后需重新核验固定区域。
- 分数是缩放 margin，不是校准概率。非零低分需连续 3 次确认；真正 0 分不能新建类别，已确认类别可在 0 分不确定结果中保持 2 次。不宣称准确率提高。
- 对照 PNG 复用历史控制图；已先核对当前二值图、骨架、路径、机器坐标及 G-code 结果完全一致，源图片和清单 SHA256 见 QUALITY.json。
- 最后一条 ok 表示控制器接收，不能证明机械 Idle、字迹可读性或实机运行成功。
