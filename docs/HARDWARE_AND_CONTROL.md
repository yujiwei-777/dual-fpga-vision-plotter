# 硬件与控制

硬件组成：HX1P35A 平台主从双板、SC500 摄像头、HDMI 显示器、板间以太网、串口无线桥接模块，以及运行 GRBL 的写字机控制器。实际电源和接线遵循开发板及执行器资料。

## 副板引脚与按键

以下引脚取自本包 secondary_doc_dirt_lowconf_factored_20261101/04_pin/pin.adc，按键低电平有效。

| 信号 | FPGA 管脚 | 行为 |
| --- | --- | --- |
| KEY1 | D5 | 接受当前识别结果，提交一次本地写字报告 |
| KEY2 | A9 | 按一下画一个固定方框，按内容高度换行；长按不持续启动 |
| KEY3 | B9 | 复位整个副板应用，影响本板处理和任务状态 |
| KEY4 | C7 | 写字任务安全停止与重置入口，保留 GRBL 状态确认流程 |
| UART TX | C18 | 接桥接模块 RX |
| UART RX | D15 | 接桥接模块 TX |
| LINK_READY 输入 | E12 | 保留物理接口；当前 UART 接纳逻辑不以该脚单独判定 GRBL 可用 |

UART 使用 **115200 baud、8 数据位、无校验、1 停止位、3.3V 电平**，收发交叉连接并共地。所有外设、DDR 和网络约束以两板 ADC / SDC 为准，不将副板按键表替代主板操作表。

主板 PCB 模式常态显示固定摆放框，按住主板 KEY4 触发识别；松开后保留最近状态。副板本地 KEY4 用于写字控制，两块板的同名按键作用不同。

## 写字通信

副板输出 ASCII G-code，每行以 LF 结束，采用逐行 stop-and-wait：收到上一条的 ok 后再发下一条。已发出但未确认的运动命令不盲目重发，以免重复运动。

正常任务在最后一条命令收到 ok 后完成逻辑任务并允许后续请求；ok 表示控制器接收命令，不等于机械已经停止。问号状态查询和新鲜 Idle / Hold 的确认保留给启动检查、停止和恢复等流程。

KEY4 停止 / 重置链路使用 GRBL 实时控制和状态确认；异常、Alarm、Reset 或状态未知时不得当作正常完成。KEY3 只复位 FPGA 应用，本身不能保证外部写字机停稳，不替代执行器急停。

当前固定笔参数：抬笔 Z=-1.20 mm、落笔 Z=+5.00 mm；空走 F7000、绘制 F3000、笔升降 F1200。单位为 mm/min，实际机械速度还受 GRBL 最大速度、加速度及短线段限制。

采用绝对坐标 G90 和毫米 G21。报告 / KEY2 使用 G54；文档流依赖预先选择并校准的工作坐标系，不应宣称每条文档任务都会重新发送 G54。先校准工作坐标、确认纸面方向及 Z 行程。

## 图像与任务

- 普通 CNN 报告包含名称、图像中心点坐标和 margin 分数；图像坐标不是写字机毫米坐标。
- PCB 使用固定窗口 (x=158,y=140,w=956,h=412)，经硬件公式采样为 96×96 Y8；可见框与模型输入契约应一起核对。
- 文档复制保留整帧比例与 320×180 网格。每格读取 4×4 源块，基础黑笔规则为至少两个 Y≤112；固定脏斑区域另有本版补偿。
- 文档、矢量报告和测试路径使用统一一次 X 镜像及边界检查；页面不足会拒绝任务，不自动越界。
- 已接受写字任务不因以太网断开自动取消或在重连后重放；UART / GRBL 故障独立进入停止与恢复流程。

ESP32 无线侧封装和固件不在本次源工程核验范围，接入者需使用匹配的桥接实现。
