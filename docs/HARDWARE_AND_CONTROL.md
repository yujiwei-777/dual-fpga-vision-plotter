# 硬件与控制（2026-11-13）


## 硬件连接

摄像头接主板；主板 HDMI 接显示器；两板用板载以太网相连。写字机使用运行 GRBL 的执行控制器，串口无线桥接固件需另行配置。

| 副板信号 | FPGA 管脚 | 连接/含义 |
| --- | --- | --- |
| UART TX | C18，J1-1 | 接桥接 RX |
| UART RX | D15，J1-2 | 接桥接 TX |
| LINK_READY | E12，J1-3 | 保留接口，不能单独代表 GRBL 安全就绪 |
| GND | J1-30 | 模块共地 |
| KEY1 / KEY2 / KEY3 / KEY4 | D5 / A9 / B9 / C7 | 低电平有效 |

UART 为 115200、8N1、3.3V。DDR、摄像头、HDMI 与 RGMII 完整引脚以各工程 ADC 为准；不把 FPGA 管脚号当作外接插针序号。

## 主板模式

SW4:SW3：00 普通 CNN、01 PCB、10 文档、11 保留。SW1 控制运动叠加；**本版板间以太网固定连接副板，SW2 控制识别/阶段信息叠加**，不是旧版的 PC/副板传图选择。

PCB 模式下，主板 KEY4(C7) 消抖后触发一次采集识别；松开再按才能触发下一次。最近结果显示在左下；黄色 SUSPECT 框内有点状中心准线。框来自副板结果，不是纸张或机器坐标标定框。

## 副板按键

| 按键 | 短按 | 长按 |
| --- | --- | --- |
| KEY1 | 提交当前模式已锁存 CNN/PCB 报告或已准备文档，需先完成上纸确认 | 上纸待确认时执行抬笔 Y 边界确认；约 2 秒触发一次，不排队普通写字 |
| KEY2 | 一个固定方框，完成后按内容高度换行 | 至少 2 秒执行一次退纸；松开不会补画方框 |
| KEY3 | 复位整个副板应用 | 同一复位入口 |
| KEY4 | 写字任务停止/重置，走 GRBL 暂停及状态确认 | 按住不连续触发 |

两板 KEY4 功能不同。KEY3 的 FPGA 复位不等于外部机器停稳；任务停止使用 KEY4 及执行器的实际停机措施。

## 首次放纸与书写

1. 烧录 `01_bit/` 中对应两板的 bit，连接 UART/GRBL，并预先校准 X 工作坐标、笔升降和机械方向。
2. 上纸待确认时，将 A4 新纸人工放在滚筒大致中部，长按副板 KEY1。抬笔后依次执行 G90、G92 Y148.50、G0 Y30.00、G0 Y267.00、G0 Y30.00，查询并等待新鲜 Idle，最后 G92 Y0。每条 G-code 都等待 ok。
3. 上纸确认成功后才允许普通报告、文档和 KEY2。确认后的本地 Y 预算为 237 mm，逻辑首行 origin_y=10 mm；下移按整个内容高度计算。纸满时拒绝新任务。
4. CNN/PCB 先识别并锁存结果，再短按副板 KEY1 书写。文档模式等待帧完整接收和规划准备完成，再短按 KEY1 提交路径。没有新快照/路径时不重放旧任务。
5. 换纸时长按 KEY2 至少 2 秒：毫米、绝对坐标、抬笔、相对 Y+297 mm、回绝对坐标、等待新鲜 Idle、G92 Y0。人工放新纸后再次长按 KEY1 确认。

上纸流程并不自动检测纸边，名义 ±20 mm 是设计允许的人工误差，滚筒方向、行程、打滑与实际纸边余量仍需实机核对。维护时 X 不移动；G92 只用于所述纸张维护的 Y 重建，不能按早期“所有任务永不 G92”的说明操作。

## 任务与故障

逐行 stop-and-wait：收到上一行 ok 才发下一行。普通任务最后 ok 表示控制器接收完成，不保证机械完全停止。维护/停止/恢复需要新的 Idle 或相应安全状态；过期 Idle、Hold 不能冒充上纸确认成功。

网口断开后已接受书写继续，重连不重新开始。Alarm、Reset、UART 异常或超时不盲目重发已发送运动命令，不自动返回纸面起点；重新建立安全坐标和上纸确认前不接纳新任务。KEY4 先暂停并查询状态，保留现有重置/恢复保护。
