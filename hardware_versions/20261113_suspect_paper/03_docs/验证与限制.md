## 实板与算法边界

当前配对 **NOT_RUN**。未把旧版用户实测结论转移给本版。纸张滚筒方向、打滑、机械边界、抬落笔、准线与纸面报告对应、断网继续与停止恢复尚待本组合验证。副板 setup 仅 7 ps，不能视为充足余量。

SUSPECT 为疑似区域提示，不是像素级缺陷分割。历史缺角命中 21/24、缺焊盘 25/44，后者未达到既定 80% 目标；本次准线和资源优化不改变这些算法准确率。普通 CNN margin 不是概率；文档固定机位脏斑补偿对更换相机或机位的效果不能直接推广。

完整包还保留历史失败尝试和未合入候选。它们不能当作当前成功路径，也不应混用模型、约束或 bit。配对身份与历史外部路径清单见 `04_verification/`。
