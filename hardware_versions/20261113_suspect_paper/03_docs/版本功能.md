# 版本功能

主板 main_pcb_suspect_center_20261113；副板 secondary_pcb_airwalk_stroke_cont_20261113。

- SC500 1280×720 采集、HDMI 叠加、图像风格化、运动区域检测和成像控制沿用本版源码。
- 普通 CNN：9 类，64×64 RGB8 ROI，远距离增强权重和 FC_CONF_SHIFT=8；书写名称、原图中心坐标与实际 margin 分数，低分结果也可呈现。分数不是正确概率。
- PCB：CCL 找候选，96×96 Y8、C4/C4 二分类。GOOD 最小 margin 为 192，BAD 为 32；弱 GOOD 转 REVIEW。主板 KEY4 每次稳定按下启动一次，长按不连拍；没有背景学习或现场录入良品模板。
- SUSPECT：保留副板疑似区域和报告中心；主板用黄色边框和框内每 8 像素一点的准线标记中心。中心是原图半开框中心，不施加机器 X 镜像，不代表已获得精确缺陷定位。
- 文档：整帧保持比例映射 320×180，每格 4×4 源像素判定，保留黑笔阈值、局部固定脏斑补偿、细化及端点优先/分叉拆笔。先准备路径，再由短按 KEY1 提交；不是 OCR 或标准汉字笔顺。
- 报告：单线矢量字模，允许相邻同笔段连续落笔；统一一次 X 镜像、按内容高度换行、页面预算检查。KEY2 短按画一方框并换行。
- 纸张维护：KEY2 长按至少 2 秒退纸；人工把新纸置于滚筒大致中部后，长按 KEY1 上纸确认。维护只移动 Y，不改变 X 基准和镜像。
- 已接受任务由副板锁存，板间断网不自动取消或重放。串口/GRBL 异常独立锁定。正常书写最后一条 G-code 收到 ok 后结束逻辑任务；维护和安全流程保留新鲜 Idle 屏障。
- HDMI 写字操作面板按状态显示，空闲隐藏；已有 Type21 数值字段尚未呈现为 N/M 或百分比进度。

主板为这次新配对明确指定了当前副板。副板原始发布报告中较早的主板路径是历史记录，不是本交付包的烧录选择。
