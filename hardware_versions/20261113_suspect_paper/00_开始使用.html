  2. 运行 python -B verify_package.py，看到 PACKAGE_VERIFY_PASS。

接线与按键速查

摄像头接主板，HDMI 接显示器，两板以太网连接。副板 UART TX=C18，RX=D15，115200 / 8N1 / 3.3V，与桥接模块交叉连接并共地。

主板 SW4:SW3：00 CNN、01 PCB、10 文档。SW2 控制显示叠加，板间网络固定走副板。主板 KEY4 每按一次识别 PCB 一次。

副板：KEY1 短按书写已锁存报告/已准备文档，长按用于待确认新纸；KEY2 短按一方框，长按至少 2 秒退纸；KEY3 全应用复位；KEY4 写字任务停止/重置。

先上纸确认：人工把纸放在滚筒大致中部，长按副板 KEY1 执行抬笔 Y 边界检查；确认成功前不接纳书写。换纸长按 KEY2，退纸后人工放新纸再长按 KEY1。
