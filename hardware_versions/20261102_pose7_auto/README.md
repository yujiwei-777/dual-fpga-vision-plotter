# 自动定位 PCB 双板工程归档

主板：main_pcb_auto_compat_20261101；副板：secondary_pcb_pose7_goodonly_ccl_20261102。

副板采用最终 r5 冻结输入，包含 CCL 最大候选定位、96×96 Y8 输入、0/180° 判向和良品空间异常评分。score≤106 为 PASS，107..204 为 REVIEW，≥205 为 FAIL；分数不是置信度百分比，不输出未经验证的缺陷位置。主板按一次 KEY4 接受一个任务，显示副板返回的实际检测框和左下角状态，PCB 结果等待预算为 30 秒。

普通 CNN、文档复制、矢量字模、镜像、换行和写字机通信的功能与验证范围见原始发布说明。旧固定摆放框不再是自动定位裁剪边界。

## 校验与工程入口

运行 python -B verify_package.py，核对完整文件集合、冻结输入映射、证据和 bit 哈希。两板根目录的 AL 为相对路径入口，File 引用分别为主板 138 条、副板 83 条。仅工程入口路径经过整理；RTL、模型和约束保持原字节。副板原始入口保存在 evidence/original_entries。

完整使用厂商工具前，应在另一个独立目录准备构建，保留初始化文件、include、IP 子文件和工作目录布局。runs 与 evidence 中的历史脚本、清单及日志可能含原机器绝对路径，不能直接作为跨机器一键构建脚本。本归档未执行新综合、布局布线或 bitgen。

## 构建记录与实板状态

主板 setup/hold WNS 为 +0.384/+0.020 ns，Slice 92.93%、ERAM 83.33%、DSP 92.50%。副板为 +0.002/+0.017 ns，Slice 91.13%、ERAM 80.56%、DSP 40.00%；两板 TNS 为 0。主板原始检查仍含 RUN-8007 和 USR-8450，独立物理容量与 IO 对照检查通过，不将其描述为无警告版本。

此组合的配对实板验收状态为 NOT_RUN。原版的实测记录不适用于这组新哈希。副板只支持 0/180° 判向；开发集回放不能替代独立准确率。30 秒预算需要结合实板端到端耗时复核。正常最后一条 ok 是 GRBL 接收确认，不代表机械 Idle。

生成数据库和仿真缓存未收录；原始哈希及排除原因保存在 SOURCE_AND_EVIDENCE_MAPPING.json。通过文件校验不等于重新执行原始构建或仿真。
