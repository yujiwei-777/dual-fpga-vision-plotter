主板：main_pcb_auto_compat_20261101

## 校验

解压到短英文路径后执行：

    python -B verify_package.py

PACKAGE_MANIFEST.json 记录文件大小、SHA256 和 bit 身份；SOURCE_AND_EVIDENCE_MAPPING.json 记录冻结输入及证据来源。校验不需要 FPGA 工具，也不会重新综合。

主板保留 189 项冻结输入；副板保留 r3 的 360 项冻结输入及完整内容寻址证据。主板另外补齐工程引用的 AutoExcluded 文件。副板 evidence/release_r3/RELEASE_MANIFEST.json 将原始证据路径映射到 evidence/<SHA256>/文件名，包含仿真、CDC/FIFO/DDR、物理检查、时序、只读重导入、bitgen 和历史失败记录。
